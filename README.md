# Proyecto

Landing page profesional desarrollada con Node.js, Express, React, Vite, Tailwind CSS y SQLite.

## Tecnologías

- **Backend:** Node.js, Express 5, SQLite
- **Frontend:** React 19, Vite, Tailwind CSS v4
- **Control de versiones:** Git y GitHub
- **Despliegue:** AWS

## Estructura del proyecto
Proyecto/
├── backend/     # Servidor Express y API REST
├── frontend/    # Interfaz de usuario en React
├── docs/        # Documentación del proyecto
└── database/    # Base de datos SQLite
## Requisitos previos

- Node.js 24 LTS o superior
- npm

## Cómo ejecutar el proyecto

### Backend

```bash
cd backend
npm install
npm run dev
```

El servidor queda corriendo en `http://localhost:3001`.

### Frontend

```bash
cd frontend
npm install
npm run dev
```

La aplicación queda disponible en `http://localhost:5173`.
